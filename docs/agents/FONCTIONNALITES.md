# Registre des fonctionnalités à préserver

Toute fonctionnalité existante de NIGHTFALL a une ligne ici, avec la preuve qui
montre qu'elle fonctionne encore. Une ligne ne disparaît jamais sans l'accord écrit du
propriétaire (règle 7) ; `tools/agents/preserve.py` le vérifie en CI.

Format d'une ligne : `| F-xxx | Domaine | Fonctionnalité | Où (fichiers) | Preuve automatique | Vérification manuelle |`.
Les raccourcis clavier s'écrivent dans la colonne Fonctionnalité sous la forme
``raccourci: `Ctrl+T` `` pour être suivis aussi.
