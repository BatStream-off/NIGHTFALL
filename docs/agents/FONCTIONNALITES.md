# Registre des fonctionnalités à préserver

Toute fonctionnalité existante de NIGHTFALL a une ligne ici, avec la preuve qui
montre qu'elle fonctionne encore. Une ligne ne disparaît jamais sans l'accord écrit du
propriétaire (règle 7) ; `tools/agents/preserve.py` le vérifie en CI.

Format d'une ligne : `| F-xxx | Domaine | Fonctionnalité | Où (fichiers) | Preuve automatique | Vérification manuelle |`.
Les raccourcis clavier s'écrivent dans la colonne Fonctionnalité sous la forme
``raccourci: `Ctrl+T` `` pour être suivis aussi.

Registre établi par la mission M-0001 sur la version 0.1.4 de `develop` (tentative 1), corrigé par la tentative 2 après l'audit `docs/agents/missions/M-0001-registre-fonctionnalites/audit-1.md`.

Ce qui a été vérifié (tentative 2, par lecture du code et par un script de contrôle) : chaque citation `fichier:symbole` de la colonne « Où » désigne un fichier existant qui contient ce symbole ; chaque test `chemin::nom` cité est une fonction `#[test]` existante ; chaque étape `step("…")` existe dans `app/src/nf/selftest.rs` ; chaque contrôle `ci.yml::…` existe dans `.github/workflows/ci.yml` ; le classement de chaque preuve a été décidé en lisant le test ou l'étape cités. Ce qui n'a pas été vérifié : le comportement réel de l'application (rien n'a été exécuté pour ce registre) ; la colonne « Vérification manuelle » est une procédure proposée, pas un constat.

La colonne « Preuve automatique » commence par un classement :
- **prouvée** : la preuve citée exerce le comportement décrit par la ligne. Quand la ligne décrit un comportement, les commandes d'interface qui ne font que le déclencher ne sont pas exigées ; quand la ligne décrit un élément d'interface (bouton, menu, panneau, page, raccourci), cet élément doit lui-même être exercé.
- **partielle** : la preuve exerce une partie seulement ; ce qui n'est pas testé est écrit après « non testé ».
- « aucune » : aucune preuve ne teste la ligne ; une parenthèse dit, le cas échéant, pourquoi un test voisin ne compte pas.
Un rendu non vide de `ci/ui_render_test.js` (la page n'est pas blanche) ne suffit jamais à rendre une ligne prouvée : seul, il donne au plus une preuve partielle.

Raccourcis : `Ctrl+…` est la forme Windows et `Cmd+…` la forme macOS du même raccourci (touche principale). Un raccourci propre à un seul système est suivi de « (Windows) » ou « (macOS) ». Les limites sont dans la section « Limites connues », pas dans les tableaux.

## Limites connues

Ces points ne sont pas des fonctionnalités : ce sont des manques ou des écarts constatés en lisant le code. Ils ne doivent pas être présentés comme réalisés.

- **L-01 Extensions Chrome** : Le bouton « Installer / gérer » de la page Extensions ouvre chrome://extensions/, qui ne fonctionne pas avec le mode de rendu Alloy utilisé : les extensions Chrome ne sont pas installables. Seule l'analyse du risque d'un manifeste est réalisée (constat de lecture du code, non testé).
- **L-02 DRM et codecs** : Widevine (DRM) et les codecs H.264 et AAC ne sont pas fournis par la version de CEF utilisée : les contenus protégés ou dans ces formats peuvent ne pas se lire (constat de lecture, non testé).
- **L-03 Quitter la page ?** : Aucune demande de confirmation « Quitter la page ? » (beforeunload) n'est affichée à la fermeture d'un onglet ou d'une fenêtre.
- **L-04 Enregistrer la page** : « Enregistrer la page » télécharge seulement le document HTML de la page, pas ses ressources (images, styles).
- **L-05 Correcteur orthographique** : Disponible seulement sur macOS ; sur Windows il reste désactivé pour ne rien envoyer aux serveurs de Google.
- **L-06 Langue de l'interface** : « Langue de NIGHTFALL » est une étiquette fixe (français) : aucune autre langue d'interface n'existe.
- **L-07 Signaux d'Auto-Purge jamais produits** : Les signaux « signature du binaire invalide » (BinarySignatureInvalid) et « module injecté » (InjectedModule) existent dans les règles et sont cités par l'interface de l'Auto-Purge, mais aucun code de l'application ne les produit aujourd'hui. Seuls sont produits : option interdite au lancement, magasin de clés altéré, base altérée et échecs répétés du code.
- **L-08 Économiseur de batterie** : Le champ PerfConfig.battery_saver n'a ni interface ni effet.
- **L-09 Formulaires en cours d'édition** : Pour la mise en veille des onglets, l'indicateur editing_form est toujours faux : un onglet avec un formulaire en cours de saisie peut être mis en veille.
- **L-10 Réutilisation de mot de passe** : La fonction password_reused_elsewhere du coffre existe mais n'est utilisée par aucun écran.
- **L-11 Anti-phishing : adresse IP et connexion en HTTP jamais signalées** : `app/src/nf/security.rs:phishing_check` appelle `check(url, false)` (aucun champ de mot de passe n'est jamais détecté). Dans `crates/nf-security/src/phishing.rs:check`, les motifs « adresse IP » (IpAddressHost) et « connexion en HTTP » (InsecureLogin) exigent `has_password_field = true` : ils ne se déclenchent donc jamais depuis la navigation, et un site désigné par une adresse IP ne reçoit aucun avertissement (le contrôle s'arrête avant les autres motifs). Le test `crates/nf-security/src/phishing.rs::ip_and_http_login` passe `true` : il teste un chemin que l'application n'utilise pas, c'est pourquoi il n'est cité comme preuve d'aucune ligne.
- **L-12 Synchronisation limitée** : La synchronisation ne concerne que les favoris, sans leurs dossiers (folder: vide) ; une suppression locale n'est pas transmise aux autres appareils.
- **L-13 Enregistrement des mots de passe** : La ligne « Enregistrement des mots de passe » des Paramètres n'est qu'une information : aucune proposition automatique d'enregistrement n'est faite sur une page de connexion.
- **L-14 Préférences de Nouvel onglet** : L'affichage des raccourcis, des statistiques et de l'horloge de la page Nouvel onglet est conservé dans le stockage local de la page, pas dans les réglages de NIGHTFALL.
- **L-15 Statistiques de Nouvel onglet** : Les données et le temps économisés affichés sont des estimations, pas des mesures.
- **L-16 Raccourcis actifs sur l'écran de verrouillage (constat de lecture, non confirmé par un test ; non corrigé dans M-0001)** : `app/src/nf/client.rs` fournit le même gestionnaire de clavier (`keyboard_handler` → `on_pre_key_event`) à toutes les vues, interface comprise, et ni `on_pre_key_event` ni `app/src/nf/api.rs:shortcut` ne vérifient que NIGHTFALL est déverrouillé (contrairement aux commandes de l'API, filtrées par `PRE_UNLOCK`). Au verrouillage, `app/src/nf/windows.rs:on_locked` masque le contenu mais garde les onglets ouverts. Effets probables d'après le code : Ctrl+P / Cmd+P imprime la page masquée ; F12 / Ctrl+Maj+I ouvrent les outils de développement s'ils sont activés ; Ctrl+Tab et Ctrl+Maj+T changent d'onglet et `activate_tab_title` écrit le titre de l'onglet dans la barre de titre de la fenêtre ; Ctrl+W ferme des onglets ; Ctrl+S enregistre la page. À confirmer par un test et à corriger dans une mission dédiée (point H1 de l'audit).
- **L-17 Mises à jour automatiques** : Pas de mise à jour automatique pour la version portable Windows ni pour une copie de développement macOS : la nouvelle version doit être installée à la main.
- **L-18 Performances** : Aucun benchmark comparatif avec un autre navigateur n'est fourni (bench/README.md décrit le protocole : aucune mesure comparative n'a encore été réalisée).
- **L-19 Signature du code** : Les exécutables ne sont pas signés par un certificat payant : Windows SmartScreen et macOS Gatekeeper affichent un avertissement à l'installation.
- **L-20 Ce qui n'est pas testé automatiquement** : L'interface n'est vérifiée que par un rendu non vide (ci/ui_render_test.js) et par l'auto-test de bout en bout ; la plupart des raccourcis clavier, des menus et des réglages n'ont pas de test dédié (voir la section Couverture).
- **L-21 Dossier de téléchargement affiché** : la page Téléchargements affiche toujours « Les fichiers sont enregistrés dans votre dossier Téléchargements » (`app/ui/downloads.js`, élément `#dir`), même quand un autre dossier a été choisi dans les Paramètres.
- **L-22 Mise en veille manuelle d'un onglet** : la commande d'API `tab.discard` existe (`app/src/nf/api.rs`), mais aucune page ni aucun menu ne l'appelle : seule la mise en veille automatique (F-178) est accessible.
