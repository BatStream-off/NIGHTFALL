## 7. Constats exécutés (moteur et API de Shield)

- Redirection — règles `||ads.example^$script,redirect=noopjs` → bloquée : true (annulée, aucune ressource de substitution)
- removeparam — règles `$removeparam=utm_source` → bloquée : false ; `should_block` ne renvoie qu'un booléen, l'URL réécrite est perdue
- Directive !#if false — règles `!#if false ⏎ ||iffalse.example^ ⏎ !#endif` → bloquée malgré la condition fausse : true
- $popup — règles `||popunder.example^$popup` → règle chargée : false (`rules_loaded` = 1)
- $document — règles `||badware.example^$document` → moteur : bloquer = true ; Shield (navigation principale) : false
- $method=post — règles `||collect.example^$method=post` → bloquée (Shield passe toujours GET) : false
- Scriptlet inconnu — règles `news.example##+js(nonexistent-scriptlet)` → script injecté contient un appel : false
- $elemhide — règles `@@||news.example^$elemhide ⏎ ##.ad` → masquage générique toujours appliqué : false
- $generichide — règles `@@||news.example^$generichide ⏎ ##.ad` → masquage générique appliqué : false
- Compteur « règles » — règles `[Adblock Plus 2.0] ⏎ ||a.example^$popup ⏎ example.com#$#abort-on-property-read x ⏎ ||b.example^` → `rules_loaded` = 4 pour 1 règle réellement chargée
- Cadre tiers (iframe) — règles `||widget.example^$third-party ⏎ widget.example##.inner-ad` → script de l'iframe widget.example contient `.inner-ad` : true
